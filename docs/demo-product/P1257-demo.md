# 시연용 상품 — 관리자 화면에서 직접 등록

DB에 바로 insert하는 20개(`src/main/webapp/sql/insert_new_products.sql`)와 달리,
이 상품 1개는 **관리자(admin) 계정으로 로그인 → "상품 등록" 화면(`addProduct.jsp`)에서
아래 값을 그대로 입력해 직접 등록하는 시연용**입니다.

이미지 파일은 같은 폴더의 `P1257.jpg`이고, 등록 폼의 "이미지 등록" 항목에서
이 파일을 선택하면 됩니다. (등록하면 시스템이 자동으로 `P1257.jpg`로 저장합니다.)

출처: 다나와(danawa.com) 상품 페이지

## 입력값

| 항목 | 값 |
|---|---|
| 상품 코드 | `P1257` |
| 상품명 | 에보니아 이오 컵홀더형 에어레더 가죽 리클라이너 1인용 |
| 상품 가격 | `245000` |
| 상품 설명 | 리클라이너 / 1인용 / 인조가죽(PU) / 크기(가로x세로x높이): 82x75x105cm / 색상: 다크그레이, 라이트그레이, 다크브라운, 다크블루 |
| 제조사 | 에보니아 |
| 상품 분류 | sofa |
